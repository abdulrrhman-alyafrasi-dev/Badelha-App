# 🔄 منصة بدلها (Badelha App)

## 📌 وصف مختصر
منصة بدلها للمقايضة الذكية والتبادل المباشر والدائري للسلع، مبنية باستخدام Flutter و Laravel 13 و PostgreSQL 18 وفق معمارية النطاق النظيف (Clean Architecture).

## 👥 أعضاء الفريق
- **عبدالرحمن اليفرسي** (`abdulrrhman-alyafrasi-dev`) - مسؤول البنية التحتية، المصادقة، وقواعد البيانات
- **سلطان العمراني** (`Sultan-Al-Amrani`) - مسؤول محرك المطابقة الذكية والمقايضة الدائرية

## 🛠️ التقنيات المستخدمة
- **Frontend**: Flutter (Dart)
- **Backend**: Laravel 13 (PHP)
- **Database**: PostgreSQL 18 & SQLite
- **DevOps & Version Control**: Git & GitHub
